# Лабораторная работа №2. Подготовка скриптов для создания таблиц и добавления данных

Данный проект содержит утилиты для организации ETL-процесса переноса исходных данных из текстовых файлов каталога `dataset` в базу данных **SQLite** (`movies_rating.db`).

## Требования к окружению

Для корректной работы скриптов на компьютере должны быть установлены:
1. **Python 3.x** (с доступными стандартными библиотеками `csv`, `os`, `sys`, `re`).
2. **SQLite3 CLI** (утилита командной строки `sqlite3`).
3. **Bash / Git Bash** (для Unix/Linux и Windows при запуске `.bat`/`.sh` скриптов).

## Структура базы данных (`movies_rating.db`)

База данных содержит следующие таблицы:
* **movies** (`id`, `title`, `year`, `genres`)
* **ratings** (`id`, `user_id`, `movie_id`, `rating`, `timestamp`)
* **tags** (`id`, `user_id`, `movie_id`, `tag`, `timestamp`)
* **users** (`id`, `name`, `email`, `gender`, `register_date`, `occupation`)

При повторном запуске скрипта существующие таблицы пересоздаются заново (`DROP TABLE IF EXISTS ...`).
